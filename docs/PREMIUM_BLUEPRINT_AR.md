# وثيقة التأسيس الشاملة لمشروع "المثالي للدعاية والإعلان"

## 1. تحليل المشروع (Project Analysis)
- **الهدف:** بناء منصة إلكترونية (Corporate Premium Landing Website) تعكس الفخامة والاحترافية، وتستهدف قطاعات الأعمال الكبرى (B2B) والجهات الحكومية.
- **الرسالة:** بناء الثقة، زيادة طلبات عروض الأسعار، تحويل الزوار إلى عملاء محتملين عبر الواتساب.
- **التوجه العام:** تصميم فخم (Luxury)، عصري (Modern)، وبسيط (Minimal) يركز على سهولة الاستخدام وتجربة المستخدم الممتازة.

## 2. هيكلة المعلومات (Information Architecture)
يتكون الموقع من أقسام متكاملة ومترابطة لدعم رحلة العميل:
1. **القسم الرئيسي (Hero Section):** رسالة قوية، دعوة لاتخاذ إجراء (طلب عرض سعر)، وتصميم بصري يعكس الفخامة.
2. **شريط الثقة (Trust Bar):** شعارات العملاء (جهات حكومية، شركات كبرى) وشهادات الآيزو (ISO).
3. **من نحن ولماذا المثالي؟ (Value Proposition):** إجابة مباشرة عن سبب اختيار "المثالي" وتميزها في السوق.
4. **حلولنا وخدماتنا (Services):** تفصيل للخدمات (الهوية المؤسسية، التسويق الرقمي، الخ) مع تصميم بطاقات فخم (Premium Cards).
5. **القطاعات المستهدفة (Industries):** كيف نخدم قطاعات (العقارات، المطاعم، الصحة، التعليم، الخ).
6. **أعمالنا ولغة الأرقام (Stats & Portfolio):** استعراض الإنجازات بلغة الأرقام لتعزيز الموثوقية.
7. **الأسئلة الشائعة (FAQ):** قسم مخصص لدعم محركات بحث الذكاء الاصطناعي (AEO) يحتوي على إجابات مباشرة.
8. **نموذج التواصل وطلب عرض السعر (Quotation Form):** نموذج احترافي متصل بإنشاء رسالة واتساب تلقائية.
9. **التذييل (Footer):** روابط سريعة، معلومات التواصل، ومعلومات الهيكلة لمحركات البحث.

## 3. هيكلة الملفات (Folder Structure)
تم بناء الهيكلة لتدعم التوسع المستقبلي:
```text
/src
  /assets         # الصور والخطوط
  /components
    /ui           # المكونات الأساسية (أزرار، حقول إدخال، بطاقات)
    /sections     # أقسام الصفحة (Hero, Services, Contact...)
    /seo          # مكونات تحسين محركات البحث والـ Schema
  /config         # ملفات الإعدادات (site.config.ts, images.ts)
  /hooks          # دوال مساعدة مخصصة (Custom Hooks)
  /layouts        # الهيكل العام (Navbar, Footer)
  /utils          # دوال مساعدة (Formatters, Validators)
  /types          # تعريفات TypeScript
```

## 4. نظام التصميم (Design System)
- **الألوان (Color Palette):**
  - **اللون الأساسي:** أزرق مؤسسي داكن (Corporate Navy) - يعكس الثقة والأمان.
  - **اللون الثانوي:** ذهبي فاتح أو فضي فخم (Champagne/Silver) - يعكس الفخامة والجودة.
  - **الخلفيات:** أبيض ناصع، ورمادي فاتح جداً للأقسام المتبادلة لراحة العين.
- **الخطوط (Typography):**
  - عناوين (Headings): خط **Cairo** (أوزان ثقيلة وبارزة).
  - نصوص (Body): خط **Tajawal** (أوزان خفيفة ومتوسطة لقراءة مريحة).
- **العناصر البصرية:** زوايا دائرية ناعمة (Rounded-xl)، ظلال خفيفة للبطاقات (Soft Shadows)، تفاعلات دقيقة عند التمرير (Micro-interactions).

## 5. شجرة المكونات (Component Tree)
- `AppLayout` (يحتوي على إعدادات RTL)
  - `Header` (Sticky Navigation)
  - `HeroSection` (Main Call to Action)
  - `TrustIndicators` (Logos & Certifications)
  - `AboutSection`
  - `ServicesGrid`
  - `TargetIndustries`
  - `FaqSection` (GEO & AEO Optimized)
  - `QuotationForm` (Form Validation -> WhatsApp)
  - `Footer`

## 6. استراتيجية المحتوى (Content Strategy)
- **النبرة (Tone):** احترافية، موثوقة، مباشرة، وموجهة للأعمال (B2B).
- **المحتوى:** سيركز على النتائج والعوائد على الاستثمار (ROI). كل قسم سيجيب عن تساؤلات العميل (لماذا نحن؟ ماذا نقدم؟ كيف نبدأ؟).
- **الدعوات لاتخاذ إجراء (CTAs):** ستكون بارزة مثل "اطلب عرض سعر الآن"، "تواصل معنا عبر واتساب"، "استشر خبرائنا".

## 7. استراتيجية تحسين محركات البحث (SEO Strategy)
- **Semantic HTML:** استخدام وسوم HTML5 بشكل صحيح (`<article>`, `<section>`, `<header>`) لسهولة قراءة العناكب.
- **Schema.org:** تضمين `LocalBusiness`، `Organization`، و `FAQPage` في ترويسة الموقع.
- **Core Web Vitals:** الاعتماد على التحميل الكسول للصور (Lazy Loading)، وتقليل حجم الأكواد لضمان تقييم 95+ في الأداء.
- **البيانات الوصفية:** تجهيز (Meta Titles, Descriptions, OpenGraph) متوافقة مع تويتر وفيسبوك.

## 8. استراتيجية بحث الذكاء الاصطناعي (AI Search & GEO Strategy)
- **الإجابات المباشرة (AEO):** صياغة المحتوى في قسم الأسئلة الشائعة ونبذة الشركة بطريقة "سؤال وجواب" واضحة لتدريب نماذج الذكاء الاصطناعي (ChatGPT, Gemini) على استخراج المعلومات بسهولة.
- **كثافة الكيانات (Entity Density):** ربط اسم "المثالي للدعاية والإعلان" بمصطلحات قوية مثل (القطاع الحكومي، التسويق الرقمي بالسعودية، الهوية المؤسسية، ISO 9001).
- **الموثوقية (E-E-A-T):** إبراز معايير الأمان، إمكانية الوصول (WCAG AA)، وسجل الأعمال كدلائل قاطعة للذكاء الاصطناعي على جودة المنصة.
